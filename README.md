This repository contains **classical machine learning models** implemented using  
**scikit-learn**, **pandas**, and **Jupyter Notebooks**, trained on real-world datasets from **Kaggle**.

The goal of this project is to **build strong ML fundamentals** before moving to Deep Learning.
